# SDE-2 Prep Java

Repository for preparing for SDE-2 transition with Data Structures and Algorithms (DSA), Low Level Design (LLD), Core Computer Science (CS), and Tools.

## Structure

- `dsa/`: Data Structures and Algorithms implementations and problems
- `lld/`: Low Level Design examples including OOP, SOLID, Design Patterns, Concurrency, and System Designs
- `corecs/`: Core Computer Science topics like DB, OS, Networking, System Design
- `tools/`: Notes and examples for tools like Redis, Kafka, Docker, Kubernetes

## Getting Started

Clone the repository and start implementing the TODOs in the code files.
